## 대상과 판정 원칙

1,000건은 **검증 목표**, 아직 완료 실적이 아닙니다. 11개 분야(IT, 네트워크, 시스템, 데이터, 데이터분석, 개인정보보호, 정보통신, 클라우드, 정보보호, 소프트웨어, 정보보안)에서 실제 공고 URL을 고유 식별자로 중복 제거하고, 사람인·잡코리아를 함께 검증합니다. 모든 분야에 표본을 확보해야 하며 한 분야에서 남는 수량으로 다른 분야의 미달을 숨기지 않습니다.

- **URL 수집**: 앱의 `createImporter`가 공개 공고 본문을 확보했는지 확인. robots.txt, 로그인, CAPTCHA, 서버 시간 제한 및 공개 범위를 준수합니다.
- **분류**: 웹앱 `analyze`, `requirements` 모듈을 사용해 필수·우대/미분류와 원문 인용을 비교합니다.
- **역량 비교**: 사용자 브라우저 프로필 원본이 아닌, 민감정보를 제외한 대표 테스트 프로필로 정확한 자격증명 자동 일치만 계산합니다.
- **근거 연결·로드맵**: `buildAnalysis`, `buildRoadmap`의 원문 위치·상태 보존·3단계 작성 여부를 검사합니다.
- 모듈 체인 통과는 실제 브라우저 UI 검수와 다릅니다. **자동 통과와 수동 의미 검수 완료를 별도 집계**합니다.
- AI Agent 관련 수정은 제외하여 추후 Codex 지시 사항으로만 정리합니다.

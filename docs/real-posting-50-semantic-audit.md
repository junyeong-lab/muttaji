## 별도 확인이 필요한 의미 해석

1. 신입/경력 등 지원자 유형마다 다른 조건을 한 사람에게 모두 필수로 합치지 않기
2. 서로 다른 모집 직무/컨설팅 포지션의 요건을 분리하기
3. '필수가 아닙니다' 같은 부정 문장과 필수조건이 한 줄에 섞인 경우 원문 근거를 보존하며 분석하기
4. 한 물리행의 여러 스킬·자격증을 개별 조건으로 분리하되 원문과 근거 범위를 유지하기
5. 추출된 원문 자체가 비어 있거나 작성되지 않은 공고에서 실제 지원조건을 임의 생성하지 않기

위 사항은 **아직 Codex 미반영**입니다. 본문에 '나중에 Codex'라고 적힌 것은 완료가 아니라 보류 및 인수인계의 뜻입니다.

## 정확한 완료 판정

- 실제 사이트에서 URL 수집·분류·프로필 비교·로드맵 화면 연결: 확인된 기준의 테스트와 실행 로그를 따름.
- 실제 공고 문장의 필수·우대 **의미적 정답 여부**: 원문 행별 증빙을 검토하며 파서 오류를 수정 중. 모든 항목이 사람의 독립 검수를 통과했다는 결론은 별도 근거 없이 보고하지 않음.
- 수정 후 테스트를 실행하고 재분류 아티팩트를 보존하되, 자동 테스트 성공만으로 원문 의미 검증 완료라고 보고하지 않음.


## 실제 보유 역량을 반영한 50건 로드맵 내용 재검증 (2026-10-29)

검증 입력은 이전에 확인된 정보처리기사·SQLD·네트워크관리사 2급, 학사 졸업, 해군 사이버보안 기획·위협 분석 및 Wazuh/GNS3 실습을 **실무와 실습으로 구분한 요약 프로필**입니다. 실증명서를 가져와 검증하거나 실제 채용사의 자격 인정 여부를 확인한 것은 아닙니다.

- [실공고 50건 × 역량 비교·로드맵 내용 자동 대조 실행](https://github.com/junyeong-lab/muttaji/actions/runs/40791838248): 실제 원문 스냅샷 50건, 조건 **458개**, 자동 ‘충족’ **15개**, 준비·추가 확인 대상 **443개**, 기술적 내용·출처 연결 오류 **0개**, **21건의 별도 의미 검토 표시**.
- [전체 회귀 테스트 262개 통과](https://github.com/junyeong-lab/muttaji/actions/runs/40791937482). 학력무관, 보유 자격증명 일치 이외의 실무 경력·외국어·운전 가능 여부는 자동 충족으로 처리하지 않았습니다.
- 일반 웹앱의 로드맵 안내 개선: 운전·병역·출장 등 객관적 지원조건은 실습 대신 증빙 확인, Zabbix/Prometheus/Grafana는 지표·경보, Docker/K8s는 배포 검증, PostgreSQL은 DB 확인, 개발 언어·협업·데이터 파이프라인·외국어는 각기 다른 준비 과제로 분리했습니다. 출처에 없는 능력을 갖췄다고 표시하지 않습니다.
- 같은 범용 안내로 시작한 로드맵 항목은 최초 **188/443개**에서 도구·업무별 안내 추가 시점 **118/443개**로 줄였고, 현재는 남아 있는 조건도 원문 조건명을 직접 표기하도록 수정했습니다.
- 각 공고·각 요건의 3단계 준비 문구와 보유 자격·학력 충족 근거는 실행의 `real-50-roadmap-contents` 결과 파일에 보존되어 있습니다.

**검증 완료 범위:** 실제 50개 원문에 대해 분류 구간, 근거 행 위치, 조건별 비교 상태, 로드맵 3단계의 연결·무리한 자동 충족·기존 유형별 잘못된 조언을 검사하고 재현된 일반 코드 오류를 수정했습니다.

**남은 의미상 판단:** 21건에 ‘검토’로 표시된 복수 경력·포지션, 조건이 한 문장에 묶인 경우, 공고 자체에 명시되지 않은 필수/우대 정보는 AI Agent가 임의 해석해서는 안 됩니다. 원문에서 확정할 수 없는 경우는 확인 필요로 둡니다. 일부 항목에 대한 실제 채용사의 인정 해석까지 100% 검증 완료한 것으로 간주하지 않습니다. 관련 상세 재현 ID와 요구사항은 [Codex 후속 목록](./codex-semantic-backlog-50.md)에 남깁니다.

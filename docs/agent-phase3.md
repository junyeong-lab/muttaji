## 이번 구현

기존 비교 결과의 사용자 근거와 프로필 문구를 공고 요건에 연결하는 로컬 설명 기능을 추가했습니다. 가상 예제 전용 화면과 달리 실제 입력을 사용합니다. 비교 화면과 로드맵 모두에서 다음을 표시합니다.

- 공고가 다루는 내용에 대한 짧은 설명
- 사용자 입력과 공고를 연결한 설명
- 설명에 사용한 공고 원문 행과 사용자 입력 인용
- 지원서·프로젝트 소개·학습 준비에 활용할 방법

사용자가 출장 가능이라고 적으면 입력한 가능 여부를 설명에 활용합니다. 지역이나 상주 가능 여부를 되묻는 추가 질문은 만들지 않습니다. 계획과 미경험도 입력 그대로 보여주며 상태를 강제로 바꾸지 않습니다. 사용자에게 근거를 다시 쓰도록 요구하는 경고를 추가하지 않았습니다.

## 현재 동작의 경계

이 기능은 문장 패턴·주제 키워드·고정 설명문을 사용하는 **로컬 규칙 기반 기능**입니다. 실제 AI 모델이 복잡한 문장 의미를 이해한 결과는 아닙니다. 화면에도 `입력 기반 연결 설명 · AI 의미 분석 아님`을 표시합니다.

직접 입력한 조건별 근거를 우선 사용하고, 해당 주제에 연결되는 프로필 문구를 최대 3개까지 함께 보여줍니다. 직접 입력한 근거와 키워드로 찾은 문구는 자료의 출처가 다르며, 어떤 방식도 사용자 경험의 진위나 기업의 인정 여부를 검증하지 않습니다. 연결할 문구가 없으면 사용자 상태를 유지하고 연결된 문구가 없다고 표시합니다.

현재 지원하는 주제는 근무·출장, 협업·소통, 전공·학력, 자격증, 진로·성장 의지, Linux, 로그·관제, 프로젝트·학습 활동, 보안, 경력입니다. 여러 조건이 섞인 문장은 대표 주제를 선택하므로 세부 의미를 모두 해석한다고 보장하지 않습니다. 알 수 없는 조건은 일반 설명으로 남깁니다. 실제 모델 연동은 여전히 보류입니다.

## 기존 기능 유지

- 기존 자격증명 자동 일치와 사용자 상태·근거 입력을 유지합니다.
- 설명 결과에는 최종 판정·점수·합격 확률 필드가 없습니다.
- 기존 상태 집계와 `확인 필요 → 미충족 → 부분 충족 → 충족` 순서를 유지합니다.
- 선택 상태와 근거에 관한 기존 5자 규칙도 이번 작업에서 변경하지 않았습니다.
- 공고·프로필이 바뀌면 기존 비교·로드맵을 무효화하는 흐름을 유지합니다.
- 조건별 근거를 수정하면 연결 설명과 로드맵이 즉시 갱신됩니다.
- 설명 엔진이 없거나 오류가 나도 기존 비교·로드맵은 계속 동작합니다.
- 필수조건을 모두 충족으로 표시한 경우 `현재 필수조건은 모두 사용자가 충족으로 표시했습니다`로 안내합니다.
- 설명이 있는 로드맵 카드에는 반복되는 추가 확인 요구 대신 연결 설명과 지원 준비 안내를 표시합니다. 상태·집계는 변경하지 않습니다.

## 개인정보·비용

새 설명 엔진은 fetch, 서버 호출, 모델 호출, 로그 기록, 저장소 쓰기를 사용하지 않습니다. 공고·프로필·조건별 근거와 설명은 해당 브라우저 탭의 메모리에서 처리합니다. 프로필 5개 항목의 기존 localStorage 저장 동작만 유지합니다. 공고·비교 결과·설명은 새 저장 대상으로 추가하지 않았습니다.

입력에 포함된 지시문은 실행하지 않습니다. 사용자 문구는 인용으로 취급하고 DOM의 textContent로 렌더링합니다. 서버 API·키·환경변수·예산 설정은 변경하지 않았습니다. Push·커밋·배포는 하지 않았습니다.

- 네 가지 사용자 상태의 집계·정렬이 설명 추가 전후 동일함을 검증했습니다.
- 정보 미입력과 미경험을 자동 충족·미충족으로 바꾸지 않음을 확인했습니다.
- 입력 지시문과 HTML이 코드로 실행되지 않음을 검증했습니다.
- 설명 엔진 누락·오류에도 기존 비교·로드맵이 유지됨을 확인했습니다.
- localhost:50627의 별도 브라우저 탭에서 가상 데이터를 사용해 실제 화면 흐름을 확인했습니다. 사용자의 127.0.0.1:50627 탭은 조작하지 않았습니다.
- 출장 가능 입력의 충족 상태 유지, 원문 근거 펼치기, Linux 구축 예정 표현, 로드맵 반영을 확인했습니다. 테스트용 프로필은 삭제했습니다.

실제 OCR 정확도, 모바일 실기기, 실제 모델 의미 분석, Vercel 빌드·운영 배포는 이번 검증 범위가 아닙니다.

## 확인 방법

현재 작성한 비교 상태·근거는 새로고침하면 사라집니다. 필요한 근거는 먼저 복사해 두세요. 사용자 프로필 5개 항목은 기존대로 같은 브라우저에 저장됩니다.

1. 미리보기 화면을 새로고침해 최신 스크립트를 불러옵니다.
2. 공고를 입력하고 내 역량에서 `채용공고와 내 역량 비교하기`를 실행합니다.
3. 조건 아래의 `공고와 경험을 연결하면`, `설명에 사용한 문구 보기`, `지원 준비에 활용하기`를 확인합니다. 같은 설명이 로드맵에도 표시됩니다.

서버가 종료된 경우 PowerShell에서 저장소 폴더로 이동한 뒤 아래 명령을 실행합니다. npm.ps1 실행 정책을 변경할 필요가 없습니다.

```powershell
node scripts/preview-agent.mjs 0
```

터미널에 출력된 주소를 열고 창을 유지하세요. 0은 사용 가능한 포트를 자동 선택합니다.

## 범위와 주의점
- **비밀키 패턴 미발견 = 모든 과거 커밋·서버 환경변수·로그에 비밀이 없다는 보장은 아니다.** 이번 점검은 현재 공개 파일의 선택 검사다.
- 실제 환경변수의 **값은 읽거나 기록하지 않았다**. 민감값을 보고서·브라우저 화면·발표 파일에 포함하지 않는다.
- 모델·URL API의 **POST 실패 시나리오**, 실제 과금 차단 효과, 동시 요청 경합과 타 IP·다른 브라우저에서의 남용 억제는 **실제 운영 부하/침투시험 미실시**다.
- `store:false`는 모델 요청 설정을 나타낸다. 서비스별 데이터 취급의 전체 보증이나 제3자 저장이 전혀 없다는 법률적 선언은 아니다.
- 사용자 개인정보를 테스트 보고서에 넣지 않는다. 제출 화면에는 비식별 예시나 공개 가능 자료만 사용한다.

## 최종 제출 시 권고하는 수동 점검
1. 시크릿 창에서 사이트가 Vercel 로그인 없이 공개되는지, 빈 입력/오류/실패 안내가 정상인지 확인.
2. Vercel 환경변수에서 서버 전용 API 키를 **값을 노출하지 않은 상태로** 확인하고, GitHub Actions 로그·커밋 기록에 포함되지 않았는지 검사.
3. Supabase RPC 권한 및 공유 쿼터 값은 읽기 전용으로 점검하고, 실수로 테스트 요청 한도를 소진하지 않는다.
4. 브라우저 개발자 도구 Network에서 사용자 **AI 분석 동의 전** 외부 모델 호출이 없는지 확인.
5. 사용자 프로필과 파일 첨부를 화면 캡처할 때 계정 식별정보·이메일·전화·비밀키·CSRF 세션값 등을 마스킹한다.

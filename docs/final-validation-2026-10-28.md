## 시험 절차
1. 공개 공고에서 확인한 **직무·학력·경력·우대 문구만** 가져와 최소한의 `모집 직무 / 필수조건 / 우대사항` 표시를 부여했다. 사이트에 없는 세부 조건은 만들지 않았다.
2. 실제 앱의 규칙 파서로 요건을 추출하고, 실제 앱의 자동 자격증·학력 제안을 적용했다.
3. 같은 앱의 `buildRoadmap`으로 모든 미확정 요건에 **3단계 준비 안내**가 생성되는지 확인했다.
4. ‘확인 필요’는 부족하다는 판정이 아니라 사용자가 아직 인정 범위·증빙을 확정하지 않은 상태로 유지했다.

# 뭐따지? 통합 개발본

기준 폴더: work/muttaji-url, 개발 브랜치: feat/job-url-import. 기존 main 기반 코드와 34개 자격증 데이터를 보존하고 단계별 개발 결과를 한 앱에 연결했습니다. 이전 work/muttaji 폴더는 백업으로 남기며 새 작업은 이 통합본을 기준으로 합니다.

## 포함 기능

- 채용공고 직접 입력·분류 수정·이미지 OCR 기존 기능
- 내 역량 브라우저 저장, 자격증 자동 일치와 추천, 직접 선택하는 요건별 상태 및 로드맵
- 사용자 경험과 공고 요건의 연결 설명 및 입력 근거 표시. 사용자의 상태 선택을 자동 변경하지 않음
- 가상 Mock 분석 및 향후 모델 연결용 서버 인터페이스. 실제 모델 미연결
- 공고 URL 수집 → 원문 확인·수정 → 확인 체크 → 기존 입력창 적용 → 기존 분석

## 실행

의존성이 없는 새 압축 해제 폴더라면 먼저 `npm.cmd ci --ignore-scripts --no-audit --no-fund`를 실행합니다.

```powershell
node scripts/preview-agent.mjs 0 --live-url
```

출력된 로컬 주소를 열고 URL 수집 접근 코드에는 `local-demo-code`를 입력합니다. 서버는 127.0.0.1에만 바인딩됩니다. 이 코드는 로컬 미리보기용이며 공개 운영 인증으로 사용하면 안 됩니다. `--live-url` 없이 실행하면 가상 URL 예제만 제공합니다. 유료 AI는 두 모드 모두 호출하지 않습니다. 기존 다른 포트의 브라우저 저장 데이터는 자동 이전되지 않으므로 이전 폴더나 브라우저 데이터를 지우지 마세요.

## 링크 기능 마무리 범위

사람인·잡코리아의 제공된 실제 링크를 서버 수집기로 확인했습니다. 캐치는 사용자 미리보기 성공 보고가 있으며 별도의 사이트 전용 어댑터를 검증한 것은 아닙니다. 이 세 사이트를 현재 확인 범위로 두고 추가 사이트 확장은 진행하지 않습니다. 같은 사이트라도 로그인·차단·이미지 전용 공고 등은 실패할 수 있으며 직접 붙여넣기를 유지합니다.

사람인 55336814는 비서 공고 본문 440자, 잡코리아 50216612는 정보보호 공고 상세 포함 2679자를 수집했습니다. 공고별 원문 의미를 새로 생성하지 않으며 사용자가 적용 전에 확인합니다.

## 검증과 제한

자동 테스트: 133개 통과. SSRF/DNS/robots/리다이렉트/시간·크기 제한, 출처·사용자 검토 흐름, 기존 분류·DB·비교·추천·로드맵을 포함합니다. 새 전체 브라우저 흐름과 이미지 OCR의 기기별 동작은 자동 테스트만으로 검증되지 않습니다.

실제 모델 API, 공개 URL API 활성화, 공유 요청 제한 저장소, GitHub Push 및 Vercel 배포는 하지 않았습니다. 환경변수·API 키·기존 데이터도 변경하지 않았습니다. 새 커밋과 원격 브랜치 URL은 없습니다.

# 🐥 뭐따지? (Muttaji)

**채용공고 요구조건과 나의 역량을 비교하는 취업 준비 웹앱**

- **웹앱:** https://project-muttaji.vercel.app/
- **소스:** https://github.com/junyeong-lab/muttaji
- **프로젝트 계획:** [plan.md](./plan.md) · v3 (2026-10-28)
- **진행 상태:** 기능 구현·실제 정보보호 컨설턴트 공고 1건 통합 확인 완료, 실제 공고 10건 확대 검증과 최종 제출 품질 점검 진행 중

## 주요 기능
| 기능 | 내용 | 주의 사항 |
| --- | --- | --- |
| 채용공고 입력 | 텍스트 붙여넣기, 선택적 URL에서 공개 채용공고 가져오기 | 사이트 정책·차단·본문 구조에 따라 실패 가능 |
| 1차 분석 | 규칙 기반 기업·모집 직무·담당업무·필수·우대 분류, 원문 행 표시, 사용자의 분류 수정 | 모델 판단이나 채용사 해석 보증 아님 |
| 내 역량 입력 | 목표 직무·학력/전공·경력/프로젝트·보유 자격증·기술/지식 | 입력 기본 보관 위치는 사용 브라우저의 `localStorage` |
| 요건 비교 | 확인 필요 → 미충족 → 부분 충족 → 충족; 직접 확인·근거 입력 | 학사 졸업과 공고의 단독 대졸 이상, 자격증 정확 명칭 자동 일치는 **본인 입력 기준** |
| 선택적 AI Agent 분석 | 명시적 동의와 사용자가 누르는 실행 동작을 통해 공고·프로필 연결 분석 | 서버와 외부 모델로 입력 전송, 제공 응답은 보조 설명이며 사용자 재확인 필요 |
| 자격증 검색 | 사용자 선정 34개 IT·정보보안 관련 자격증의 검색·분야 필터·참고 추천 | 시행기관의 자동 검증이나 실제 자격 취득 증명 아님 |
| 취업 준비 로드맵 | 원문 근거, 사용자 상태별 우선순위, 각 요건 3단계 준비 제안 | 준비 기간·합격 가능성·경력 대체 자동 산출 안 함 |

### 이미지 공고 안내
브라우저의 이미지 업로드 및 앱 내 OCR은 **운영 버전에서 제거**했습니다. Windows 사용자는 Microsoft PowerToys 텍스트 추출기 **Win + Shift + T**를 사용해 글자를 복사한 뒤 공고 입력창에 붙여넣을 수 있습니다. [Microsoft 공식 설치 안내](https://learn.microsoft.com/ko-kr/windows/powertoys/install).

## 사용 방법 (3단계)
1. **채용공고**에서 URL을 가져오거나 원문을 붙여넣고 ‘텍스트 1차 분석하기’로 필수·우대 등 분류를 확인하고 잘못된 분류를 직접 고칩니다.
2. **내 역량**에서 학력·경력·기술·자격증을 입력하고 ‘채용공고와 내 역량 비교하기’를 실행합니다. 필요하면 별도의 동의 이후 AI Agent 분석을 실행합니다.
3. **로드맵**에서 확인 필요·미충족·부분 충족·충족, 공고 원문, 입력 근거와 준비 단계 3개를 확인합니다.

## 실제 검증 내용과 미확인 범위
- **사용자 실사용 확인:** 정보보호 컨설턴트 공고를 URL로 수집해 필수·우대 10개 요건 비교, 공학사 졸업의 단독 ‘대졸 이상’ 자동 충족, 실제 AI 분석 응답, 네 가지 상태 로드맵 및 요건별 준비 3단계를 확인했습니다. **충족 1개 / 확인 필요 9개**는 ‘본인 입력’ 결과이며 정확도 보증이 아닙니다.
- **수정·재확인:** 중복된 직무명 정리, 근무지 오분류 방지, ‘프로그래밍’과 로그 분석 혼동 방지, 공고에 명시되지 않은 Python 요구사항 제거, 졸업예정·재학 자동 충족 방지.
- **서버 상태:** 운영의 `/api/session`, `/api/model-analysis`, `/api/job-url-import` GET 응답으로 기능 활성화 여부를 확인할 수 있습니다. **GET 성공은 유료 모델 실행이나 10건 전체 URL 수집 성공을 뜻하지 않습니다.**
- **최종 점검 예정:** 실제 공고 10건의 출처별 검증, 시크릿 창 공개 접근, 모바일·접근성, 자격증 필터, 오류/한도 초과, 서버·개인정보 보안 점검과 발표·최종 제출 증빙.
- 전수 검증되지 않은 항목은 완료로 표시하지 않으며 실제 외부 공고나 채용사 인정에 관한 판단은 사용자가 다시 확인합니다.

## 저장·보안·운영 원칙
- 규칙 기반 텍스트 분석·역량 대조는 기본적으로 브라우저에서 실행됩니다.
- URL 가져오기와 **동의 후 실행하는 AI Agent**는 서버 요청을 사용합니다. 프로필/공고가 외부 모델로 전달되는 범위와 개인정보 포함 여부를 입력자가 확인해야 합니다.
- 개인별 학력·경력·자격증은 자신이 입력한 사실을 토대로만 비교합니다. 자격증으로 실무경력이나 다른 자격 종목을 대체하지 않습니다.
- 공개 코드에 API 비밀키를 넣지 않고 서버 환경변수·요청 제한·비용 예산을 사용합니다. 보안 점검 결과가 미확인인 항목은 별도로 기록합니다.
- URL 수집은 공개 페이지 및 사이트 정책에 한정하며, 차단/접속 실패 시 직접 붙여넣는 방법을 제공합니다.

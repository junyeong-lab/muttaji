# 🐥 뭐따지? (Muttaji)

**AI가 알려주는 나만의 취업 준비 가이드**

> 채용공고를 입력하면 요구사항을 분석하고 사용자 역량과 비교하여, 무엇을 준비할지 실행 순서로 알려주는 웹앱 MVP 프로젝트.

## 현재 상태 (2026-10-21)

- **완료:** 서비스 기획, 기존 캐릭터·디자인 시안, 발표자료, 자격증 DB 초기 Excel 템플릿, [프로젝트 계획서 v2](./plan.md), 반응형 웹 UI 첫 버전, 메뉴 이동, 채용공고 텍스트 입력·이미지 미리보기, 내 역량 입력 폼의 입력 확인
- **진행 전:** 자격증 23개 공식 정보 검증, AI 텍스트·이미지 분석 API, 실제 사용자 역량 비교·저장, 개인별 자격증 추천, 자동 로드맵, 실제 사용 테스트
- **검증 범위:** GitHub 소스 파일과 JavaScript 문법 확인. 브라우저에서 검색·필터 실제 조작 검증은 별도 확인이 필요합니다.
- **자격증 검색(2026-10-22):** 확장본 Excel에서 자격증 23개를 가져와 `data/certifications.json`에 저장하고 검색·분야 필터 UI를 구현했습니다. 제공된 자격 구분·시행기관·응시자격 등은 공식 검증 전 자료이므로 확정 정보로 취급하지 않습니다.
- 이 저장소의 `muttaji/` 디렉터리는 기존 ALEPH 과제 코드와 분리하여 관리합니다.
- 초기 템플릿과 디자인 시안은 **운영 DB나 작동하는 앱이 아닙니다.**

## MVP의 핵심 흐름

채용공고 텍스트/이미지 → 필수·우대 요건 구분 → 내 역량 입력·비교 → 공식 검증된 자격증 정보 매칭 → 취업 준비 로드맵

- 퍼센트 적합도·합격 확률을 임의로 산출하지 않습니다.
- 자격증 보유를 실무 경력 충족으로 간주하지 않습니다.
- 채용공고 URL 크롤링, Google Play 출시, 결제는 초기 MVP 범위가 아닙니다.
- 사용자가 제공한 기존 「뭐따지?」 브랜드 보드의 병아리 포스터를 경량 WEBP로 추출해 [홈 화면](./index.html)에 반영했습니다. 새로운 캐릭터를 생성하지 않았습니다.
- 공고 입력 및 내 역량 입력은 현재 **브라우저 내 입력 확인** 단계입니다. 서버 전송·저장·AI 분석을 수행하지 않습니다.
- 아직 분석 결과나 실제 추천이 없는 곳에는 개발 예정 상태를 명시했습니다.

## 진행 순서

1. 자격증 DB 스키마 및 공식 정보 검증
2. 기존 UI 기반 웹앱 화면 — **초기 화면·이동·입력 UI 구현, 브라우저 검증 대기**
3. 채용공고 텍스트·이미지 분석
4. 사용자 역량 비교 및 자격증 추천
5. 맞춤형 준비 로드맵과 예외 처리
6. 실제 공고 테스트 및 Vercel 배포

# 🐥 뭐따지? (Muttaji)

**IT 취업준비생을 위한 채용공고 분석 및 자격증 탐색 웹앱**

채용공고 URL 또는 텍스트를 입력하면 규칙 기반으로 담당업무·필수조건·우대사항을 분류합니다. 사용자가 결과를 직접 확인·수정하고, 보유 자격증과 공고에 명시된 자격증 및 기술·분야가 연관된 참고 후보를 구분해 살펴볼 수 있습니다.

## 현재 제공하는 기능

| 기능 | 내용 |
| --- | --- |
| 공고 입력 | 공개 채용공고 URL 가져오기 또는 텍스트 붙여넣기. 추출한 본문은 직접 확인·수정 후 적용 |
| 규칙 기반 분류 | 담당업무·필수조건·우대사항 등을 분류하고 근거가 된 원문 행 번호 표시 |
| 분류 수정 | 사용자가 항목의 분류와 적용 범위를 직접 변경 |
| 보유 자격증 입력 | 보유 자격증과 목표 직무 입력, 브라우저 내 저장 |
| 공고 명시 자격증 | 공고에 직접 명시된 자격증을 안내하고 보유 입력과 구분 |
| 기술·분야 연관 후보 | 관련 기술·분야에 따른 참고 후보를 최대 3개 범위에서 안내 |
| 자격증 DB | 74개 레코드의 이름·관련 역량 검색, 분야 필터, 발급·시행기관 및 관련 정보 조회 |

74개는 데이터 레코드 수이며 모두가 현재 취득 가능한 개별 시험이라는 뜻은 아닙니다. 국가기술·민간·국제 자격 등의 유형과 검증 상태를 구분합니다. 과거 자격·종료 시험 및 세부 인증이 불명확한 검색용 기록은 취득 추천에서 제외합니다. 최신 응시자격·공인 여부·시험 운영 상태는 공식기관에서 확인해야 합니다.

## 확인하는 방법 · 3단계

1. 채용공고 URL 또는 텍스트를 입력해 담당업무·필수조건·우대사항 분류 결과를 확인하고 수정합니다.
2. 보유 자격증을 입력한 뒤, 공고에 직접 명시된 자격증과 기술·분야가 연관된 참고 후보를 구분해 확인합니다.
3. 자격증 DB에서 이름·분야별 검색과 발급기관·관련 역량 정보를 확인합니다.

## 최종 범위와 변경 이유

초기 계획의 AI 역량 분석·자동 충족 판정·취업 준비 로드맵은 검증 정확도와 사용 흐름을 고려해 최종 사용자 화면에서 제외했습니다. 규칙 기반 공고 분석과 자격증 탐색에 집중하고 DB를 74개로 확장했습니다.

분석 결과는 AI의 의미 판단이나 채용사의 자격 인정 결과가 아닙니다. 연관 후보는 공고에 명시된 필수·우대 자격증을 뜻하지 않으며, 취득·지원 자격·합격 가능성을 자동 판정하지 않습니다.

## 실제 사용 확인

사용자가 제공한 화면과 최종 발표자료를 기준으로 SK텔레콤 2026 Junior Talent Tech 직군의 **SW개발·AI Model 두 모집 분야**에서 공고 입력, 분류 결과 확인, 연관 자격증 표시 흐름을 기록했습니다. 이 공고는 앱의 활용 사례이며, 앱이 특정 기업 전용이라는 의미는 아닙니다.

| 화면에서 확인한 항목 | SW개발 | AI Model |
| --- | --- | --- |
| 원문 행 | 27 | 40 |
| 담당업무 분류 | 16 | 23 |
| 필수조건 분류 | 9 | 15 |
| 우대사항 분류 | 0 | 0 |
| 공고 직접 명시 자격증 | 없음 | 없음 |
| 기술·분야 연관 후보 | 3개 | 2개 |

위 숫자는 당시 입력에 대한 앱 표시 결과입니다. 분류 수 자체가 정확도 검증은 아니며, 원문 행 수와 항목 수는 단위가 다릅니다. '공통' 같은 소제목의 필수 항목 분류, 졸업예정·졸업 후 기간 등 선택 조건 해석에는 사용자 확인이 필요합니다. 자세한 근거와 한계는 [현재 상태](docs/current-status.md)에 정리했습니다.

## 입력·운영 안내

- URL 수집은 공개 페이지 및 사이트 정책을 따릅니다. 로그인·CAPTCHA·접근 제한을 우회하지 않으며, 실패하면 텍스트를 직접 붙여넣습니다.
- 앱 내 이미지 업로드와 OCR 기능은 제공하지 않습니다. 현재 화면에는 이미지 공고의 텍스트를 외부 도구로 복사하는 안내가 남아 있습니다.
- 보유 자격증 등 입력 정보는 브라우저에 저장합니다. 공용 PC에서는 앱의 저장 정보 삭제 기능을 사용하세요.
- URL 가져오기는 서버 요청을 사용합니다. 기본 공고 분류·자격증 검색은 외부 AI 호출 없이 동작합니다.
- 공개 AI API 진입점은 비활성 응답을 반환합니다. 과거 AI·비교·로드맵 모듈과 테스트가 저장소에 남아 있는 것은 현재 제공 기능을 뜻하지 않습니다.

## 프로젝트 구성

- `index.html`: 최종 사용자 화면과 검색·입력 흐름
- `assets/job-text-analyzer.js`, `assets/job-category-corrections.js`: 규칙 기반 분류와 수동 수정
- `assets/certification-recommendations.js`: 공고 명시 자격증·기술/분야 연관 후보 안내
- `assets/job-url-ui.js`, `api/job-url-import.js`, `lib/job-url/`: 공개 URL 본문 가져오기
- `data/certifications.json`: 74개 자격증 레코드와 분류·검증 상태
- `tests/`: 현재 기능과 과거 모듈의 회귀 테스트
- `docs/`: 현재 제출 문안·기능 상태와 구분 표시된 과거 개발 기록

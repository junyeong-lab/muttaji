01 · 채용공고 분석

어떤 공고가 궁금하세요?

AI 원문 분석과 기존 텍스트 분석 중 선택할 수 있습니다. 분석 결과를 직접 확인·수정한 뒤 내 역량 비교와 기존 로드맵으로 전달합니다.

AI 제안 → 사용자 확정
공개 채용공고 URL 가져오기 · AI 자동 호출 없음

채용공고 링크로 본문 가져오기

공개 HTML을 가져온 뒤 직접 확인·수정합니다. 로그인·CAPTCHA·접근 제한은 우회하지 않으며, 실패하면 기존 텍스트 붙여넣기를 사용할 수 있습니다.

이미지로만 된 공고는 링크에서 문자를 가져오지 못할 수 있습니다. Windows PowerToys의 텍스트 추출기(Win + Shift + T)로 화면의 글자를 복사해 아래 입력창에 붙여넣어 주세요.

URL 가져오기 기능을 준비하고 있습니다.

추출 결과 확인·수정

수집 당시 정보와 근거 보기

적용하면 아래 입력창의 기존 내용을 바꿉니다. 적용 취소로 이전 내용으로 되돌릴 수 있습니다. 근거 목록은 수집 당시 원문이며 수정한 내용의 출처를 자동 보증하지 않습니다.

적용 후 AI 원문 분석 또는 기존 텍스트 분석을 선택할 수 있습니다. 기존 텍스트 분석은 외부 AI로 공고를 전송하지 않습니다.

0자 입력됨최대 20,000자 · AI 원문 분석 또는 아래 기존 텍스트 분석을 선택하세요. 분류와 적용 범위는 직접 확인해 주세요. 이미지 공고는 Windows PowerToys의 텍스트 추출기(Win + Shift + T)로 글자를 복사한 뒤 이곳에 붙여넣어 주세요.

AI Agent로 원문 전체 분석하기

기존 규칙 분류 목록을 정답으로 사용하지 않고, 원문 전체에서 기업·직무·업무·필수·우대·참고·확인 필요 항목을 제안합니다. 내 역량은 이 단계에서 전송하지 않습니다.

이름·연락처 등 불필요한 개인정보는 제외해 주세요. 앱은 분석 결과를 저장하지 않습니다. 제공자의 보안·오남용 감시 보관 정책은 별도로 적용됩니다.

AI 연결 상태를 확인하고 있습니다.

텍스트 분석 · 기존 방식 (AI 미사용)

AI 원문 분석이 실패하거나 결과가 나오지 않으면 이 기능을 이용하세요. 위에 붙여넣은 채용공고를 기존 규칙 기반 방식으로 분류합니다. OpenAI API를 호출하지 않으며 AI 전송 동의도 필요하지 않습니다. 분석 후 필수·우대조건을 직접 확인·수정하고 내 역량 비교와 로드맵을 이어서 사용할 수 있습니다.
🔎 현재 분석 흐름
AI 원문 분석 또는 기존 텍스트 분석 → 분류 확인·수정 → 내 역량 비교입니다. AI 분석에 동의하고 실행할 때만 공고 원문을 외부 AI로 전송합니다. AI 분석이 작동하지 않으면 왼쪽의 기존 텍스트 분석을 선택하세요.
필수조건과 우대사항을 어떻게 나누나요?AI가 표의 제목, 실제 업무, 지원 조건과 우대의 의미를 원문 근거와 함께 제안합니다. 확정 전까지 기존 비교에 반영하지 않으며 애매한 항목은 확인 필요로 남깁니다.
이미지 공고 입력 방법별도 이미지 업로드 기능은 제공하지 않습니다. Windows에서 PowerToys의 텍스트 추출기를 활성화한 뒤 Win + Shift + T로 글자를 복사해 붙여넣고, 인식된 내용을 확인한 뒤 분석해 주세요.
설치하지 않았다면 Microsoft Store에서 ‘Microsoft PowerToys’를 검색하거나 Microsoft 공식 PowerToys 설치 안내를 확인해 주세요.

AI 제안 검토 · 승인 전에는 비교에 반영되지 않습니다

원문 전체와 참고 정보에 누락된 조건이 없는지 확인하세요. 분류, 원문 인용, 적용 직무·지원 유형을 수정할 수 있습니다. 직무별 조건은 ‘내 비교 대상에 포함’을 직접 선택하세요.

공고에서 확인된 내용

줄바꿈으로 나뉜 글자는 같은 불릿(ㆍ, - 등) 아래에서 이어진 문장으로 합쳐 표시합니다. 임의로 문장을 만들어내지 않으며 원문 대조가 필요합니다. 이 결과는 공고의 제목·복합 제목·번호 매기기를 이용한 규칙 기반 분류입니다. 원문을 확인하고 잘못된 분류는 직접 변경할 수 있습니다. AI가 의미를 이해하거나 사실을 검증한 결과가 아닙니다. 항목별 근거가 된 원문 줄 번호를 함께 표시합니다. 채용 요건 충족 여부와 자격증 추천은 아직 계산하지 않습니다.
02 · 나의 역량

지금 가진 경험부터 적어볼까요?

확인할 수 있는 사실만 적어주세요. 없는 자격증이나 경력을 임의로 채우지 않습니다.

필수·우대 요건 직접 비교 가능
입력 내용의 자동 저장은 이 브라우저에서 수행합니다. AI 분석에 동의하고 실행하면 공고와 내 역량이 서버 및 OpenAI로 전송됩니다. 공용 PC에서는 아래 삭제 버튼을 사용하세요.
현재 단계 · 보유역량과 공고 비교

내 역량으로 요건을 점검해 볼까요?

AI를 사용하지 않는 규칙 기반 비교 기능입니다. 공고의 단독 자격증명 조건과 보유 자격증명이 일치하거나, 대졸 이상 조건에 학사 졸업 사실이 명시되면 충족(본인 입력 기준)으로 자동 표시합니다. 졸업예정·재학·전공·경력·기술 등은 별도로 직접 확인해야 합니다. 자동 표시는 공식 자격 보유 검증이나 합격 가능성 판정이 아닙니다.
진행 순서: ① 공고 원문 입력 → AI 또는 기존 텍스트 분석 선택 ② 분류·적용 범위 검토 및 수정 ③ 내 역량 입력 및 비교. 기존 텍스트 분석은 AI 없이 실행되며 AI 결과와 구분됩니다.

확정한 조건과 내 경험 연결하기 · 별도 AI 보조 의견

확인한 공고와 내 역량을 OpenAI로 보내 분석합니다. 이름·연락처 등 불필요한 개인정보는 제외해 주세요. 결과는 보조 의견이며 선택한 상태를 변경하지 않습니다.

앱은 분석 결과를 저장하지 않습니다. 응답 저장은 끄지만 제공자의 보안·오남용 감시 보관 정책은 별도로 적용됩니다.

실제 AI 연결 상태를 확인하고 있습니다.

필수·우대 조건별 본인 확인

요건별 확인 결과

공고에 명시된 자격증명(또는 일부 우대 자격증 목록)과 보유 자격증 입력이 일치하거나, 학력무관 또는 단독 대졸 이상·명시된 학사 졸업 조건에 해당하면 해당 요건만 자동 표시됩니다. 졸업예정·전공·경력 등 다른 조건은 직접 검토해 주세요. 자동 표시는 본인 입력과 공고 문구에 근거하며 채용사의 자격 인정이나 합격 가능성을 확정하지 않습니다.

입력한 경험과 공고의 연결 설명을 함께 표시합니다.

이 비교 결과는 본인이 입력한 자격증명과 공고 문구의 규칙 기반 일치 여부를 포함한 자체 점검 기록입니다. 보유 자격증의 증빙은 별도 확인이 필요하며, 기업의 실제 지원 자격 인정이나 합격 가능성을 평가하지 않습니다. 내 역량 입력만 이 브라우저에 저장되며 비교 결과는 새로고침 시 다시 실행해야 합니다.
03 · 자격증 DB

자격증을 찾아볼까요?

직접 선택하고 공식 자료와 대조하신 자격증 34개를 이름·분야·관련 역량으로 검색합니다.

34개 · 공식자료 검증 사용자 확인

공고와 관련된 자격증 찾아보기

채용공고 또는 목표 직무를 바탕으로 선택한 34개 DB에서 연관 자격증 최대 3개를 안내합니다.

공고 또는 목표 직무를 입력한 뒤 실행해 주세요.

※ 공고에 자격증명이 명시된 경우와 관련 기술에서 찾은 참고 후보를 구분합니다. 취득·지원 자격·합격 가능성을 자동 판정하지 않습니다.
🔎 검색 기능은 동작하지만, 아직 AI 자격증 추천은 아닙니다.
목록의 자격 구분·시행기관·응시자격은 사용자가 공식 자료와 대조를 마쳤다고 확인한 정보입니다. 최신 응시자격 및 변경 사항은 시행기관 사이트에서 다시 확인하세요. DB 검증과 개인의 자격증 보유 여부 또는 채용 요건 충족 판정은 별개입니다.
자격증 목록을 불러오는 중입니다.
04 · 취업 준비 로드맵

지금 확인할 것부터 차근차근

채용공고와 내 역량 비교 결과를 바탕으로 필수조건부터 확인·보완할 순서를 정리합니다.

규칙 기반 · AI 추천 아님

아직 비교한 결과가 없어요

먼저 채용공고의 필수·우대 조건과 내 역량을 비교해 주세요. 요건별 상태를 입력하면 이 브라우저에서만 준비 순서가 생성됩니다. 비교 결과는 새로고침하면 사라지며 자동으로 경력이나 합격 가능성을 평가하지 않습니다.

나의 요건별 준비 현황

각 조건의 ‘준비 단계 3개 보기’를 펼치면 규칙 기반 실행 안내를 확인할 수 있습니다. 실제 충족 여부를 자동 판정하거나 준비 기간을 계산하지 않습니다.

확인 필요 → 미충족 → 부분 충족 → 충족 순서입니다. 같은 상태에서는 필수조건을 먼저 표시합니다.

01 · 채용공고 분석

어떤 공고가 궁금하세요?

채용공고를 텍스트로 분석하고 원문을 확인한 뒤 자격증 추천 메뉴에서 관련 자격증을 확인하세요.

텍스트 분석 · 직접 확인
공개 채용공고 URL 가져오기

채용공고 링크로 본문 가져오기

공개 HTML을 가져온 뒤 직접 확인·수정합니다. 로그인·CAPTCHA·접근 제한은 우회하지 않으며, 실패하면 기존 텍스트 붙여넣기를 사용할 수 있습니다.

이미지로만 된 공고는 링크에서 문자를 가져오지 못할 수 있습니다. Windows PowerToys의 텍스트 추출기(Win + Shift + T)로 화면의 글자를 복사해 아래 입력창에 붙여넣어 주세요.

URL 가져오기 기능을 준비하고 있습니다.

추출 결과 확인·수정

수집 당시 정보와 근거 보기

적용하면 아래 입력창의 기존 내용을 바꿉니다. 적용 취소로 이전 내용으로 되돌릴 수 있습니다. 근거 목록은 수집 당시 원문이며 수정한 내용의 출처를 자동 보증하지 않습니다.

적용 후 아래 텍스트 분석 버튼을 누르고 분류 결과를 직접 확인·수정해 주세요.

0자 입력됨최대 20,000자 · 아래 텍스트 분석을 실행한 뒤 분류와 적용 범위를 직접 확인해 주세요. 이미지 공고는 Windows PowerToys의 텍스트 추출기(Win + Shift + T)로 글자를 복사한 뒤 이곳에 붙여넣어 주세요.

채용공고 텍스트 분석

입력한 채용공고를 기존 규칙 기반 방식으로 분석합니다. 분석 결과에서 담당업무·필수조건·우대사항을 직접 확인·수정하세요. 별도 AI 호출 없이 자격증 추천·검색 메뉴로 이어집니다.
🔎 분석 순서
공고 입력 → 분류 확인·수정 → 보유 자격증 입력 → 자격증 추천 순서로 진행하세요. 분류가 애매하면 원문과 대조해 주세요.
필수조건과 우대사항을 어떻게 나누나요?공고의 제목과 구간 표기를 기준으로 먼저 분류합니다. 복잡한 표나 조건은 잘못 분류될 수 있으니 결과에서 직접 확인하고 수정해 주세요.

공고에서 확인된 내용

줄바꿈으로 나뉜 글자는 같은 불릿(ㆍ, - 등) 아래에서 이어진 문장으로 합쳐 표시합니다. 임의로 문장을 만들어내지 않으며 원문 대조가 필요합니다. 이 결과는 공고의 제목·복합 제목·번호 매기기를 이용한 규칙 기반 분류입니다. 원문을 확인하고 잘못된 분류는 직접 변경할 수 있습니다. AI가 의미를 이해하거나 사실을 검증한 결과가 아닙니다. 항목별 근거가 된 원문 줄 번호를 함께 표시합니다. 채용 요건 충족 여부는 판정하지 않습니다. 자격증 추천은 별도 메뉴에서 실행합니다.
02 · 내 자격증

보유한 자격증을 입력하세요

취득한 자격증과 관심 직무만 입력하세요. 공고에 직접 나온 자격증과 관련 분야 추천을 구분해 보여드립니다.

보유 입력 기준 · 취득 증빙 별도
보유 자격증과 목표 직무는 이 브라우저에만 자동 저장됩니다. 공용 PC에서는 아래 삭제 버튼을 사용하세요.
현재 단계 · 보유역량과 공고 비교

내 역량으로 요건을 점검해 볼까요?

AI를 사용하지 않는 규칙 기반 비교 기능입니다. 공고의 단독 자격증명 조건과 보유 자격증명이 일치하거나, 대졸 이상 조건에 학사 졸업 사실이 명시되면 충족(본인 입력 기준)으로 자동 표시합니다. 졸업예정·재학·전공·경력·기술 등은 별도로 직접 확인해야 합니다. 자동 표시는 공식 자격 보유 검증이나 합격 가능성 판정이 아닙니다.
진행 순서: ① 공고 원문 입력 → 텍스트 분석 ② 분류·적용 범위 직접 확인·수정 ③ 내 역량 입력 및 비교.

필수·우대 조건별 본인 확인

요건별 확인 결과

공고에 명시된 자격증명(또는 일부 우대 자격증 목록)과 보유 자격증 입력이 일치하거나, 학력무관 또는 단독 대졸 이상·명시된 학사 졸업 조건에 해당하면 해당 요건만 자동 표시됩니다. 졸업예정·전공·경력 등 다른 조건은 직접 검토해 주세요. 자동 표시는 본인 입력과 공고 문구에 근거하며 채용사의 자격 인정이나 합격 가능성을 확정하지 않습니다.

입력한 경험과 공고의 연결 설명을 함께 표시합니다.

이 비교 결과는 본인이 입력한 자격증명과 공고 문구의 규칙 기반 일치 여부를 포함한 자체 점검 기록입니다. 보유 자격증의 증빙은 별도 확인이 필요하며, 기업의 실제 지원 자격 인정이나 합격 가능성을 평가하지 않습니다. 내 역량 입력만 이 브라우저에 저장되며 비교 결과는 새로고침 시 다시 실행해야 합니다.
03 · 자격증 DB

자격증을 찾아볼까요?

등록된 자격증을 이름·분야·관련 역량으로 검색할 수 있습니다.

기존 34개 + 신규 후보 · 검증 상태 구분

공고와 관련된 자격증 찾아보기

공고에 직접 명시된 자격증은 모두 보여주고, 관련 분야 후보는 전체 3개 범위 내에서 안내합니다.

채용공고 또는 목표 직무를 입력한 뒤 추천을 실행해 주세요.

※ 공고에 자격증명이 명시된 경우와 관련 기술에서 찾은 참고 후보를 구분합니다. 구 자격·종료 시험 및 세부 인증이 불분명한 검색용 기록은 취득 추천에서 제외합니다. 취득·지원 자격·합격 가능성을 자동 판정하지 않습니다.
※ 자격증 추천 및 검색 결과는 참고용입니다. 최신 응시자격과 공인 여부는 발급·시행기관의 공식 안내를 확인해 주세요.
자격증 목록을 불러오는 중입니다.
04 · 취업 준비 로드맵

지금 확인할 것부터 차근차근

채용공고와 내 역량 비교 결과를 바탕으로 필수조건부터 확인·보완할 순서를 정리합니다.

규칙 기반 · AI 추천 아님

아직 비교한 결과가 없어요

먼저 채용공고의 필수·우대 조건과 내 역량을 비교해 주세요. 요건별 상태를 입력하면 이 브라우저에서만 준비 순서가 생성됩니다. 비교 결과는 새로고침하면 사라지며 자동으로 경력이나 합격 가능성을 평가하지 않습니다.

나의 요건별 준비 현황

각 조건의 ‘준비 단계 3개 보기’를 펼치면 규칙 기반 실행 안내를 확인할 수 있습니다. 실제 충족 여부를 자동 판정하거나 준비 기간을 계산하지 않습니다.

확인 필요 → 미충족 → 부분 충족 → 충족 순서입니다. 같은 상태에서는 필수조건을 먼저 표시합니다.

01 · 채용공고 분석

어떤 공고가 궁금하세요?

기존 규칙 기반 1차 분류를 사용하고, 별도의 AI 의미 분석 기능을 준비하고 있습니다.

1차 분석 제공 · AI 연동 준비
0자 입력됨최대 20,000자 · 명시된 항목 제목을 기준으로 구분하며, 추측은 하지 않습니다.
PNG · JPG · WEBP 파일 1개
이미지를 선택한 뒤 버튼을 누르면 한글·영문 글자를 추출할 수 있습니다.
이미지를 선택해 주세요.
이미지 OCR은 브라우저에서 수행합니다. 버튼 클릭 시 외부 CDN에서 OCR 코드·언어 데이터를 다운로드하며 이미지는 서버로 업로드하지 않습니다. 인식된 표의 열을 아래에서 직접 검토·수정한 뒤 적용합니다. AI 의미 분석은 아닙니다.

OCR 결과 검토 · 열별 수정

표의 열 위치를 보고 분류를 제안할 수 있지만, 직접 확인한 뒤 적용해야 합니다. 예를 들어 'ES기술부'는 회사명이 아닌 부서일 수 있습니다. 필수·우대가 섞인 열은 원문 제목을 유지하고 제목 인식 오류를 수정해 주세요.

🔎 현재 분석 방식
AI가 아닌 브라우저 내 규칙 기반 1차 구분입니다. 공고 텍스트는 서버나 외부 AI API로 전송하지 않습니다.
필수조건과 우대사항을 어떻게 나누나요?공고에 적힌 「담당업무」「필수 자격요건」「우대사항」 같은 제목을 기준으로 해당 문장을 구분합니다. 애매한 항목은 확인 필요로 남깁니다.
이미지 글자 추출(Beta)이미지에서 OCR로 텍스트를 추출해 입력창으로 옮깁니다. 잘못 읽힌 글자를 수정하고 1차 분석 버튼을 누르세요. AI 의미 분석은 이후 단계에서 연결합니다.
텍스트 분석 결과 · 1차

공고에서 확인된 내용

줄바꿈으로 나뉜 글자는 같은 불릿(ㆍ, - 등) 아래에서 이어진 문장으로 합쳐 표시합니다. 임의로 문장을 만들어내지 않으며 원문 대조가 필요합니다. 이 결과는 공고의 제목·복합 제목·번호 매기기를 이용한 규칙 기반 분류입니다. 원문을 확인하고 잘못된 분류는 직접 변경할 수 있습니다. AI가 의미를 이해하거나 사실을 검증한 결과가 아닙니다. 항목별 근거가 된 원문 줄 번호를 함께 표시합니다. 채용 요건 충족 여부와 자격증 추천은 아직 계산하지 않습니다.
02 · AI 의미 분석 · 선택 기능

AI로 공고의 의미 분석하기

현재 사용하는 텍스트 1차 분류는 AI가 아닙니다. 이 기능은 별도의 서버 설정을 마친 후 실제 AI 모델이 공고 문장을 해석하도록 만들어졌습니다. 사용자가 동의하고 버튼을 눌렀을 때만 텍스트를 외부 AI 제공자에게 전송합니다. 이미지 파일과 내 역량 입력은 전송하지 않습니다.

AI 분석 서버 설정을 확인하고 있습니다.

접근 코드는 이 브라우저에서 저장하지 않으며 분석 요청을 보낼 때만 사용합니다. 공개 사이트의 무단 비용 발생을 방지하기 위한 기능입니다.
8,000자 이하의 텍스트만 전송합니다. 기업명·개인 연락처 등 민감한 정보가 포함되지 않았는지 먼저 확인하세요. 실제 AI 모델 사용에 요금이 발생할 수 있습니다.
AI Gateway의 인증과 모델 목록만 확인합니다. 채용공고를 전송하거나 유료 모델을 호출하지 않습니다.

02 · 나의 역량

지금 가진 경험부터 적어볼까요?

확인할 수 있는 사실만 적어주세요. 없는 자격증이나 경력을 임의로 채우지 않습니다.

필수·우대 요건 직접 비교 가능
현재는 서버 저장 기능이 없습니다. 입력 내용은 이 페이지에서만 유지되며 새로고침하면 사라집니다.
현재 단계 · 보유역량과 공고 비교

내 역량으로 요건을 점검해 볼까요?

AI를 사용하지 않는 수동 검토 기능입니다. 공고의 필수·우대 조건을 가져오고, 사용자가 실제 이력과 대조하여 충족 / 부분 충족 / 미충족 / 확인 필요를 직접 선택합니다. 자동으로 충족을 판정하지 않으며, 선택한 상태를 인정하려면 이유·근거를 작성해야 합니다. 입력은 이 브라우저에만 있으며 서버로 전송하거나 저장하지 않습니다.
진행 순서: ① 채용공고 텍스트 입력 및 1차 분석 ② 내 역량 입력 ③ 아래 버튼으로 조건별 직접 검토

필수·우대 조건별 본인 확인

요건별 확인 결과

채용공고에서 확인된 항목마다 현재 상태와 근거를 직접 기록하세요. 비어 있는 근거는 '확인 필요'로 집계합니다. 자격증만으로 실무 경력 충족 판정을 해서는 안 됩니다.

이 비교 결과는 사용자가 직접 입력한 자체 점검 기록입니다. 기재한 경험의 진위 여부를 자동 검증하지 않으며, 기업의 실제 서류·면접 합격 가능성을 평가하지 않습니다. 브라우저 새로고침 시 초기화됩니다.

사용자 제공 자료 · 공식 검증 전

04 · 맞춤형 준비 로드맵

어떤 것부터 준비할까요?

사용자가 직접 확인한 요건별 상태와 근거를 바탕으로 준비 순서를 정리합니다.

무료 · 규칙 기반 · AI 호출 없음
자동 합격 판정이나 AI 추천이 아닙니다. 필수조건을 먼저 살피고 직접 선택한 '미충족·부분 충족·확인 필요' 항목을 준비할 순서로 나열합니다. 공고에 자격증 이름이 직접 등장할 때만 기존 DB에서 후보를 연결하며, 모든 자격 정보는 공식 검증 전입니다. 자격증이나 실습을 실무경력으로 대체할 수는 없습니다.
STEP 1공고 구분원문의 담당업무·필수·우대 조건을 확인하고 오류를 수정
STEP 2내 역량 대조실제 수행 경험과 자격증을 직접 입력하고 요건별 근거 작성
STEP 3준비 우선순위필수조건과 현재 확인 상태를 기준으로 다음 행동 정리
STEP 4증빙 준비프로젝트·공식 자격 정보·채용담당자 확인사항 기록

규칙 기반 준비 가이드 · 사용자 근거 검토 필요

나의 준비 순서

각 항목은 사용자가 입력한 사실과 상태를 정리한 실행 후보입니다. 자격 취득·경력·프로젝트의 진위 및 채용요건 충족 여부를 자동 확인하지 않습니다. 입력 데이터는 서버에 저장되지 않으며 새로고침 시 사라집니다.

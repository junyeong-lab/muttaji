로드맵 생성 예정
01 · 채용공고 입력

어떤 공고가 궁금하세요?

채용공고 내용을 붙여넣거나 캡처 이미지를 선택해 주세요.

입력 UI 구현 · AI 미연결
0자 입력됨
PNG · JPG · WEBP 파일 1개
선택한 이미지는 현재 브라우저에서만 미리 봅니다.
📌 개발 안내
현재 이 버튼은 입력 여부만 확인합니다. AI 분석이나 이미지 문자 인식 결과를 생성하지 않습니다. 외부 API로 내용을 보내지 않습니다.
필수조건과 우대사항 구분이후 AI 분석 단계에서 각 항목의 근거 문장과 함께 제시할 예정입니다.
채용공고 URL은 받지 않아요초기 MVP에서는 텍스트와 이미지 입력에 집중합니다.
02 · 나의 역량

지금 가진 경험부터 적어볼까요?

확인할 수 있는 사실만 적어주세요. 없는 자격증이나 경력을 임의로 채우지 않습니다.

입력 UI 구현 · DB 미연결
현재는 서버 저장 기능이 없습니다. 입력 내용은 이 페이지에서만 유지되며 새로고침하면 사라집니다.
03 · 자격증 DB

자격증을 찾아볼까요?

작성해 주신 IT·정보보안 분야 자격증 23개를 이름·분야·관련 역량으로 검색합니다.

사용자 제공 자료 · 공식 검증 전
🔎 검색 기능은 동작하지만, 아직 AI 자격증 추천은 아닙니다.
목록의 자격 구분·시행기관·응시자격 등은 사용자 엑셀에 입력된 검증 전 정보입니다. 최신 공식 자료 확인 후 확정되며, 자격증 보유 여부만으로 채용 요건을 충족한다고 판단하지 않습니다.
자격증 목록을 불러오는 중입니다.
03 · 취업 준비 로드맵

막막한 준비를 차근차근

준비 순서는 채용공고의 필수조건과 실제 보유역량을 확인한 뒤 정해집니다.

로드맵 생성 기능 개발 예정
아직 개인별 추천 결과는 없습니다.
아래 흐름은 서비스 설계도이며, 현재 사용자의 준비 상태를 평가한 결과가 아닙니다.
STEP 1필수조건 확인공고의 필수 자격·경력·기술 조건을 먼저 살펴봐요.
STEP 2부족한 역량 정리보유역량과 비교해 확인이 필요한 부분을 표시해요.
STEP 3학습·경험 보완자격증뿐 아니라 프로젝트와 실무 연습을 제안해요.
STEP 4지원 준비경험을 포트폴리오와 지원 자료로 연결해요.
